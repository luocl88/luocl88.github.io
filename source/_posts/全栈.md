二、先看路线图再动手

- roadmap.sh —— 全栈学习路线图，一目了然知道要学什么、什么顺序
- MDN Web Docs —— 前端权威文档，中文，查语法靠它

三、算法题的正确位置

- LeetCode 中国站 / 牛客 —— 为面试刷高频题

▎ 每周 2~3 小时刷算法，其余时间写项目。顺序别反——只刷题做不出项目，但做过项目再刷题会快很多。

给你的具体路径

你 Python 刚学完基础语法、大二，建议：

1. 先看 roadmap.sh 的全栈路线图，建立全景认知
2. freeCodeCamp 中文版从「响应式网页设计」开始 —— HTML/CSS 是绕不开的地基
3. JavaScript 是重点 —— 全栈绕不开，前端后端都靠它
4. 再选后端：Node.js（和前端同一门语言，最顺）或 FastAPI/Django（复用你现在的 Python）
5. 每学一块就做一个能跑的东西，别只看教程

▎ ⚠️ 如果目标是国内就业：后端主流是 Java + Spring Boot，前端是 Vue/React。Python 后端岗位少一些但存在。这个选择越早定越好。
