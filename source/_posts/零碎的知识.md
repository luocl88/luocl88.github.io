## pip 和虚拟环境

- pip 是 Python 的包管理工具
- pip install 包名 从 PyPI 下载安装第三方库
- pip list、pip show 包名、pip uninstall 包名
- 环境 = Python 解释器 + 已安装的包
- .venv 是项目专属的虚拟环境文件夹，里面有：
  - bin/python（指向系统 Python 的链接）
  - bin/pip
  - lib/python3.14/site-packages（包装在这里）
  - pyvenv.cfg
- .venv 不是复制整个 Python，只有 13MB 左右
- 激活：source .venv/bin/activate，退出：deactivate
- PyCharm 里选中 .venv 后，运行和 Terminal 都会自动用它
