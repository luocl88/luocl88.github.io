* `mkdir = make directory`（建目录）。`~ `是主目录的简写，等价于 `/Users/luochangli。`
* `cd ~/my-blog
git mv source/img/cover*.{png,jpg,jpeg} source/img/图库/`
点子：- `{png,jpg,jpeg}` 是大括号展开，shell 会把这行自动拆成三条匹配：`cover*.png、cover*.jpg、cover*.jpeg`，三条合起来正好 9 个文件。所以它不会碰到 python3/ 和 python3的学习/ 里的截图（那些叫 image-*.png）。
- 用` git mv` 而不 `mv：mv `只是移动文件，`git `会看成`「删掉一个旧文件 + 新增一个陌生文件」`，你以前的修改记录就断了。`git mv 等于「移动 + 告诉 git 这是改名」`，历史记录能接上。以后遇到 git 仓库里的改名，都用它。
